## 2.1.0（内置 Pandoc 版）

`versionCode 2010000` · Obsidian 1.13.7 · 内核 `ink rev 61`

> 功能级版本：**不用弱沙箱、不用原生二进制，平板与 PC 都能用真实 Pandoc 导出**；窗口形态改为
> 显式状态机；插件链（安装完整性 / 安全存储 / 日志）与设置诊断一并落地，并把 2026-11-22 两轮
> 外部审计的发现修完。

**内置 Pandoc（新）**

- 随包内置官方 Pandoc 3.10（WebAssembly，`pandoc-wasm@1.1.0`，GPL-2.0-or-later）：
  Enhancing Export、pandoc 类插件调用 `pandoc` 时自动由内置引擎执行，**无需安装 pandoc、
  无需弱沙箱权限**；平板与 PC 同一构建。
- 设备引擎的 V8 是 jitless（渲染/主进程均无 `WebAssembly`），内置引擎改在独立工具进程以
  `--no-jitless` 执行；自检 version/html/docx 三项通过，工具进程崩溃不影响主界面。
- 限制：不能输出 PDF、不联网、只支持 Lua filter（可执行 filter 明确拒绝）；pandoc 的
  `execSync`/`spawnSync` 明确报"只支持异步"，其它命令的同步调用照常执行。
- 设置「Pandoc」分区：版本/状态/位置/宿主只读信息 + 外部路径（默认内置位置）+ 自检。

**窗口与形态**

- 新增三层窗口状态机（LayoutProfile / WindowShape / PublishMode）与不变量守卫：焦点窗决定
  发布者、切窗按形状重发布；2in1 最大化/分屏/浮窗不再误发布移动布局。
- 触摸形态忽略浮窗记忆尺寸、启动铺满；自绘/原生标题条二选一，不再两套按钮重叠。

**插件链**

- 触屏模式下依赖 Node 模块的插件不再"加载失败"（`require` 判据常量化，与桌面语义一致）。
- **插件安装完整性校验**：先下载并做与内核同级的语法校验，截断体不再落盘；已坏插件有专用提示。
- **`secretStorage` 明文兜底**（引擎无 `safeStorage`，对齐内核移动端语义）：BRAT 等 1.11.4+
  插件迁移不再静默失败、设置页正常注册（密钥以明文存本地，设置页会提示未加密）。
- 渲染层日志默认 error 级落盘（可切全量/关闭），插件失败不再黑箱。

**设置与诊断**

- 设置页底部新增 Pandoc / 诊断 / 日志三个分区（普通用户默认隐藏，用「显示高级信息」展开）：
  三个诊断（通用 / Pandoc / 插件）一次只跑一个，报告为纯事实「键: 值」格式。
- 路径只给复制按钮；日志捕获/详细日志开关 + 「运行日志 / 插件错误」选项卡。
- Pandoc 外部路径检查使用真实 `child_process` 直测 execve，并标明"执行面"（原始/内置接管）。

**审计修复（rev213）**

- pandoc hook 不再伪造非 pandoc 的 `execSync`/`spawnSync`（真实 errno 重新可见）；
- pandoc wasm 锁改钉解压后 wasm 的 sha256（跨 zlib 可复现），并修正下载包校验键名；
- 门禁升级为行为 + 补丁交互（7 项）；BRAT 未收录构建文案去罪化；docs 断链修复。

**已知问题**

- 内置 Pandoc 的插件级端到端导出（docx/pptx/epub）仍需真机确认；弱沙箱
  （`CUSTOM_SANDBOX`）仍需手动签名 + AGC 受限 ACL 审核，本版不涉及。
- 旧问题保留：退出前刚改名且此后再未书写的最后一笔可能丢失；同一 PDF 在第二个窗口的
  "恢复原始 PDF"需重开文档才同步。

## 2.0.1（插件修复）

`versionCode 2000001` · Obsidian 1.13.7 · 内核 `ink rev 61`

**插件（主要修复）**

- **触屏模式下依赖 Node 模块的插件不再"加载失败"**。原因是内核给插件的 `require` 只在"模拟移动端"时生效，
  白名单（仅 `obsidian` + CodeMirror/Lezer）之外的模块一律返回 `null`；而本移植的触屏模式正是靠模拟移动端实现的，
  于是插件 `require("fs"/"path"/"electron")` 直接抛错。本移植的渲染层有完整 Node，这个 `null` 属于误判，
  现已改为始终走真实的 `require`。
- 因此**同一批插件在触屏模式与桌面窗口模式下的加载语义一致**，不会再出现"一动模式插件全变"。
- 副产品：加载成功但设置页里懒加载 Node 模块的插件，设置页也不再空白。

**手写笔**

- 绘图工具（笔/荧光笔/橡皮/套索）激活时，笔尖点在界面上会给一次提示：笔尖只画不点界面，请用手指或切回「指针」。
  拦笔行为本身不变（掌托与误触防护依赖它）。

**已知问题**

- 仍然存在的插件失败面与模式无关：内核硬拒载名单（`settings-search`、旧版 `cmdr`/`obsidian-image-toolkit`、`better-pdf-plugin` 1.4.0）、
  deprecated 版本表、真正只在移动端工作的插件、以及依赖原生模块/未实现 Electron API 的插件。
- 关闭应用前刚改过文件名、且此后再未书写时，最后一笔仍可能在退出时丢失（计划下一版补 `beforeunload` 兜底）。
- 同一 PDF 在第二个窗口打开时，"恢复原始 PDF"只对执行恢复的窗口立即生效，另一窗口重开该文档后同步。

## 2.0.0（手写线首个版本）

`versionCode 2000000` · Obsidian 1.13.7 · 内核 `ink rev 60`

> 这是 1.4.2 之后的第一个正式版：手写线整体入库，并在发布前按两轮外部审计把回归与
> 文件安全问题全部修完（见下方"发布前修复"）。

**手写笔**

- 华为 M-Pencil 压力/倾斜墨迹，笔杆双击/轻捏。
- 笔记、PDF、内嵌 PDF、Canvas 四个表面书写；墨迹侧车存 `.obsidian/ohsidian-ink/`。
- 长按拉直、一笔成形（方形/椭圆）、套索移动/复制/删除、点预测、压感橡皮、只擦荧光笔。
- 掌托过滤与笔事件仲裁；关闭手写笔模式后 PDF 不保留任何叠层。
- PDF 标注写回真实注释（`/PolyLine`，可切 `/Ink`），离开 PDF 时按脏页批量写，首次写入前备份。
- 修复 PDF 写回整体左下偏移：不再重复减 CropBox 原点。

**发布与评测**

- 新增 18 场景手写回归评测与宣传素材流水线（`scripts/stylus-eval/`）。
- agent 探针构建独立为 `scripts/build-agent.mjs`，产物只进 `artifacts/agent/`，不混入 release。
- 性能探针里的 PDF 自动滚动改为显式开启，不再影响正常阅读。
- `verify-release` 保证发布 asar 不含设备探针。

**平板与窗口**

- 触摸形态忽略浮窗记忆尺寸，修复启动画面不全屏（窗口被记忆成 869×706 的问题）。
- 2in1 保持原窗口行为，不受触摸形态整屏校正影响。

**发布前修复（对比 1.4.2）**

- 鼠标与触控板：修复主窗、弹窗、内嵌窗里**滚轮与捏合完全失效**（手写笔改动误删了引擎唯一的手势转发通道）。笔迹书写仍不会拖动页面。
- 删除：插件直接调用系统回收站删掉的文件，不再因为"内容修改时间很旧"被清理逻辑当场永久删除。
- 切换仓库：旧仓库最后几秒的编辑与窗口布局先落盘再关窗，不再丢失。
- "恢复原始 PDF"：恢复动作本身不再可能截断当前 PDF；恢复后荧光笔不再从屏幕消失，注释可在下次书写时按需重建。
- PDF 写回：备份键不再串到另一个同名 PDF；两个窗口同写一个 PDF 不再互相覆盖；单页笔迹过多时明确提示而不是静默超时。
- 文件改名/移动：墨迹侧车迁移先等保存落定、写入改为原子替换，失败会提示，不再"墨迹凭空消失"。
- 内嵌 PDF：套索"副本"不再落到页面外（也不再写进 PDF 越界注释）。
- 模式文件：返回手势不再把键盘高度、窗口几何回退成旧值。
- 设置页开关：手写笔设置里的开关恢复为 Obsidian 自己的 `<label>` 结构，不会再出现"只能开、点不灭"。

**已知问题**

- 关闭应用前刚改过文件名、且此后再未书写时，最后一笔仍可能在退出时丢失（计划下一版补 `beforeunload` 兜底）。
- 同一 PDF 在第二个窗口打开时，"恢复原始 PDF"只影响执行恢复的那个窗口；另一个窗口需重新打开该文档才同步（无数据丢失）。
- 构建与发布内部：asar 安装改为"校验 → 备份 → 原子替换"，输出目录不再残留可被误打进包的备份文件（用户不可感知，记录备查）。
