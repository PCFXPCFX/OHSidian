## 2.0.0（手写线首个版本）

`versionCode 2000000` · Obsidian 1.13.7 · 内核 `ink rev 60`

> 这是 1.4.2 之后的第一个正式版：手写线整体入库，并在发布前按两轮外部审计把回归与
> 文件安全问题全部修完（见下方"发布前修复"）。

**手写笔**

- 华为 M-Pencil 压力/倾斜墨迹，笔杆双击/轻捏。
- 笔记、PDF、内嵌 PDF、Canvas 四个表面书写；墨迹侧车存 `.obsidian/ohsidian-ink/`。
- 长按拉直、一笔成形（方形/椭圆）、套索移动/复制/删除、点预测、压感橡皮、只擦荧光笔。
- 掌托过滤与笔事件仲裁；关闭手写笔模式后 PDF 不保留任何叠层。
- PDF 标注写回真实注释（`/PolyLine`，可切 `/Ink`），离开 PDF 时按脏页批量写，首次写入前备份。
- 修复 PDF 写回整体左下偏移：不再重复减 CropBox 原点。

**发布与评测**

- 新增 18 场景手写回归评测与宣传素材流水线（`scripts/stylus-eval/`）。
- agent 探针构建独立为 `scripts/build-agent.mjs`，产物只进 `artifacts/agent/`，不混入 release。
- 性能探针里的 PDF 自动滚动改为显式开启，不再影响正常阅读。
- `verify-release` 保证发布 asar 不含设备探针。

**平板与窗口**

- 触摸形态忽略浮窗记忆尺寸，修复启动画面不全屏（窗口被记忆成 869×706 的问题）。
- 2in1 保持原窗口行为，不受触摸形态整屏校正影响。

**发布前修复（对比 1.4.2）**

- 鼠标与触控板：修复主窗、弹窗、内嵌窗里**滚轮与捏合完全失效**（手写笔改动误删了引擎唯一的手势转发通道）。笔迹书写仍不会拖动页面。
- 删除：插件直接调用系统回收站删掉的文件，不再因为"内容修改时间很旧"被清理逻辑当场永久删除。
- 切换仓库：旧仓库最后几秒的编辑与窗口布局先落盘再关窗，不再丢失。
- "恢复原始 PDF"：恢复动作本身不再可能截断当前 PDF；恢复后荧光笔不再从屏幕消失，注释可在下次书写时按需重建。
- PDF 写回：备份键不再串到另一个同名 PDF；两个窗口同写一个 PDF 不再互相覆盖；单页笔迹过多时明确提示而不是静默超时。
- 文件改名/移动：墨迹侧车迁移先等保存落定、写入改为原子替换，失败会提示，不再"墨迹凭空消失"。
- 内嵌 PDF：套索"副本"不再落到页面外（也不再写进 PDF 越界注释）。
- 模式文件：返回手势不再把键盘高度、窗口几何回退成旧值。
- 设置页开关：手写笔设置里的开关恢复为 Obsidian 自己的 `<label>` 结构，不会再出现"只能开、点不灭"。

**已知问题**

- 关闭应用前刚改过文件名、且此后再未书写时，最后一笔仍可能在退出时丢失（计划下一版补 `beforeunload` 兜底）。
- 同一 PDF 在第二个窗口打开时，"恢复原始 PDF"只影响执行恢复的那个窗口；另一个窗口需重新打开该文档才同步（无数据丢失）。
- 构建与发布内部：asar 安装改为"校验 → 备份 → 原子替换"，输出目录不再残留可被误打进包的备份文件（用户不可感知，记录备查）。
