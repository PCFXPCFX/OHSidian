# 功能与差异（相对原版 Obsidian）

> 本文说明 OHsidian 在官方 Obsidian 之上做了什么。安装与构建见 [README](../README.md)，
> 手写笔细节见 [STYLUS](STYLUS.md)，逐轮实现记录见 [CHANGES-2026-10](CHANGES-2026-10.md)。

OHsidian 最初基于 [HanversionOvO/OHSidian][upstream] 的 Electron 兼容层，现已脱离
GitHub Fork 网络独立维护。下面列的是**本移植版当前的行为**；与官方 Obsidian 桌面端
不一致的地方，都是鸿蒙平台能力差异导致的适配，而不是改了 Obsidian 的编辑内核。

## 手写笔（v2 主线）

- 华为 M-Pencil 压力/倾斜墨迹，笔杆双击与轻捏可配置。
- 笔记、PDF、内嵌 PDF、Canvas 四个表面都能写；墨迹存 `.obsidian/ohsidian-ink/` 侧车。
- 长按拉直、一笔成形（方形/椭圆）、套索移动/复制/删除、点预测、压感橡皮、只擦荧光笔。
- 掌托过滤 + 笔事件仲裁：笔不误触 Obsidian 控件，手指在笔离开 1.2s 后恢复。
- PDF 标注写回真实注释（默认 `/PolyLine`，可切 `/Ink`）；离开 PDF 时按脏页批量写，
  首次写入前备份原文件，写坏不替换。
- 完整的 18 场景回归评测与宣传素材流水线，见 [STYLUS](STYLUS.md)。

## 窗口与显示

- 按官方沉浸式规范重做窗口链路：layout fullscreen 加真实系统条 insets，触摸模式下
  状态栏与导航条正确避让；修复启动铺不满、底部死区。
- 引擎只读取一次 surface 尺寸：增加几何稳定门控与首启强制整屏，修复首次进入时
  视口超宽、控件超出屏幕。
- 触摸形态忽略浮窗记忆尺寸：即使上次留下小矩形，启动也校正为整屏（2in1 不受影响）。
- 多窗口（自由窗口）：使用系统标题条并做内容避让，消除双关闭按钮与白条；窗口矩形
  超出屏幕时自动钳制到屏幕的 80% 并居中。
- 触摸模式与多窗口模式跟随系统 PC 模式开关自动切换。

## 输入与首次启动

- 修复触摸模式下的仓库切换与管理（绕过引擎有缺陷的原生下拉弹窗）。
- 把输入法高度（`--keyboard-height`）提供给引擎，格式化工具栏正确悬浮在键盘上方。
- 修复快速开始的 “folder not found”（默认仓库重定向到可写目录）。

## 外部内容接入

- **拖入即插入**：中转站、文件管理器、截图悬浮窗的图片和文件拖到编辑器上即插入为
  附件。修复单张图片拖入时触发 “Open external link?” 且无法插入的问题。
- **跨应用文件自动取回**：其他应用沙箱里的拖拽文件由适配层借临时 URI 权限复制进
  应用缓存；本就可读的来源保持原路径直通。
- **系统分享目标（Share Kit）**：注册 `ohos.want.action.sendData`，分享面板可直接把
  图片、视频、音频、文件和文本分享到 Obsidian，插入当前聚焦的笔记；应用未运行时
  分享，启动后自动投递。
- **碰一碰 / 跨设备**：UDMF 拖拽走拖入管线，Want 形式走分享目标路径。架构与验证项
  见 [DRAG-DROP-INBOUND](DRAG-DROP-INBOUND.md)。

## 数据安全与耗电

- 应用内删除笔记统一进入回收站，不直接永久删除。鸿蒙没有对第三方应用开放的系统
  回收站 API，引擎回收站桥行为不可控，删除动作因此被改写为本地搬移。
- 回收站落点重定向到文件管理可见的 `文档/OHSidianTrash/<仓库名>/`。仓库内的 `.trash`
  以点号开头，文件管理不显示。
- 每次启动 60 秒后自动清理：超过 30 天的文件删除，空目录一并清掉。
- 命令面板提供“迁移仓库到文件管理可见的位置”，把仓库（含 `.trash`）复制到系统文件夹
  选择器授权的目录。
- 关闭自动更新，分发走本仓库 Release；引擎内更新链路保留但不会触发。
- 移除无效的云同步轮询、共享 GNSS 单订阅、亮屏锁前台守卫与日志截断，降低耗电。

## 工程与分发

- `obsidian.asar` 不入库：构建时从官方源下载、校验 SHA-256 与 RSA 签名，再注入补丁；
  `verify-asar` 校验补丁标记与语法。
- 发布构建剥离设备探针，`verify-release` 拦截残留符号；agent 探针只存在于本地
  `scripts/build-agent.mjs` 产物，永不发布。
- 关闭 Release 构建的 ArkGuard 混淆。原版以 Release 模式构建会因混淆在启动时闪退。
- GitHub Actions 全自动构建：Release 附 SHA-256 / MD5，可选签名、双桌面图标。
- `obsidian://` 深链桥接：Remotely Save 等插件的浏览器 OAuth 登录可用。
- 本移植版移除了云同步（Cloud Foundation Kit）、华为账号一键登录（AGC Account Kit）
  与 AGC 初始化；相关适配器保留为惰性代码，不再接线。

## Obsidian 核心体验

- 完整的 Obsidian 1.13.7 笔记编辑与管理功能。
- 兼容社区插件与主题。
- 本地 Vault 的创建、管理与浏览；Markdown 实时预览与编辑。
- 图谱视图、反向链接等高级特性。
- 多窗口：主窗口、子窗口、嵌入窗口与浮动窗口；位置与大小持久化；独立渲染进程。

## 文件删除与回收站

删除笔记时，文件移动到 `文档/OHSidianTrash/<仓库名>/`，保留其在仓库内的相对路径。
该目录与仓库平级，Obsidian 不索引、不同步，文件管理可以直接查看。

每次启动 60 秒后，应用扫描 `文档/OHSidianTrash/` 与各仓库的 `.trash`，删除超过 30 天的
文件（按文件修改时间计算），并清掉空目录。

| 操作 | 方式 |
|------|------|
| 恢复 | 在文件管理中把文件移回仓库对应路径，Obsidian 自动重新索引 |
| 永久删除 | 在文件管理中手动删除，没有下一层回收站 |
| 重名处理 | 第二次删除同名文件，自动追加序号，如 `笔记 (2).md` |

注意：

- 删除确认弹窗会显示本次删除的实际去向（已授权文档目录显示 `OHSidianTrash` 路径，
  未授权显示仓库内 `.trash`）。
- 删除动作只替换文件搬移这一步，不改动 Obsidian 的索引与删除对话框逻辑；搬移失败
  时自动回退到仓库内的 `.trash`。
- 回收站目录在第一次删除文件后出现。
- 不要把 `OHSidianTrash` 当作仓库打开。误开时，退出仓库并删除其中的 `.obsidian` 即可。

实现位于 `scripts/update-obsidian.mjs`：渲染端补丁替换 `adapter.trashLocal` 的搬移目标，
主进程补丁负责定时清理。
